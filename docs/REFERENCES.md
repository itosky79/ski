## 2. 公表文献の値

### 2.1 身体寸法（身長比）

出典：Drillis, R. & Contini, R. (1966), *Body Segment Parameters*.
D. A. Winter, *Biomechanics and Motor Control of Human Movement*, 4th ed. (Wiley, 2009), Table 4.1 に再録。

| 分節 | 身長 H に対する比 |
|---|---|
| 足長 | 0.152 |
| 足関節高 | 0.039 |
| 下腿（足関節〜膝） | 0.246 |
| 大腿（膝〜股関節） | 0.245 |
| 体幹（股関節〜肩） | 0.288 |
| 上腕 | 0.186 |
| 前腕 | 0.146 |
| 肩峰幅 | 0.259 |
| 大転子間幅 | 0.191 |

### 2.2 分節質量比

出典：Dempster, W. T. (1955), *Space Requirements of the Seated Operator*（同 Table 4.1 に再録）。

| 分節 | 体重に対する比（片側） |
|---|---|
| 体幹＋頭頸 | 0.497 + 0.081 |
| 大腿 | 0.100 |
| 下腿 | 0.0465 |
| 足 | 0.0145 |
| 上腕 | 0.028 |
| 前腕＋手 | 0.016 + 0.006 |

この質量比は次の 2 か所で使っています。

1. **前額面の姿勢を解く**：外傾角 α を与えたとき、質量加重重心が力学的に決まる内傾角 λ の線上に
   来るような脚の傾き φ_leg を二分法で求める（`src/kinematics.js` の `solveFrontal`）。
2. **描画した身体の重心を検算する**：リグを組んだあと各分節の重心から全身重心を計算し、
   力学的な重心と一致するよう全体を平行移動する（`src/skier.js` の `computeCoM`）。

### 2.3 雪面反力の実測値（参考）

アルペン競技の実測研究では、ピークの雪面反力は **GS でおよそ 3.2 体重、SL でおよそ 4 体重**
（瞬間的に 5 体重近く）と報告されています。本ツールは準静的モデルなので、これより小さい
1.0〜2.2 体重程度の値になります。荷重の抜き差し（アンウェイティング）や雪の変形を含めれば
実測値に近づきます。

## 3. 教材としての想定値（規定でも実測でもないもの）

以下は「わかりやすさ」のために決めた値です。指導の狙いに合わせて
`src/constants.js` で自由に変えてください。

| 項目 | 既定値 | 備考 |
|---|---|---|
| 外向角の最大値 | SL 30°／GS 18° | SL のほうが上体を谷に向け続けるため大きい |
| 外傾角の最大値 | SL 24°／GS 20° | |
| 膝の角度 | SL 8°／GS 6° | エッジ角に加算 |
| 外傾の分担 | 股関節 65 %／腰椎 35 % | 骨盤の上下軸を脚と上体の間のどこに置くか |
| 滑走速度 | SL 42 km/h／GS 65 km/h（競技レベル） | レベル係数 初級 0.45／中級 0.72／競技 1.0 |
| 斜度 | SL 22°／GS 19° | |
| スタンス幅 | SL 26 cm／GS 32 cm | |
| 内足の先行量 | SL 16 cm／GS 10 cm | |
| 外脚の荷重配分 | 切り替え 50 % → フォールライン 約 95 % | 荷重の大きさに応じて連続的に変化 |
| 軌跡 | 正弦波 w(u) = A·sin(2πu/L) | L = ポール間隔 × 2 |
